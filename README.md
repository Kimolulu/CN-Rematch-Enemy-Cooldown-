Rematch – WoW 12.1 宠物对战增强-中文版

<img src="images/ability bar.png">

针对《魔兽世界》插件 Rematch 的兼容性修复与便捷性改进，服务于 WoW 12.1 版本。
本项目最初旨在修复因 WoW 12.1 新增的“受保护/秘密值”机制而导致 Rematch 功能失效的问题，随后逐渐演变为更完善的宠物对战辅助增强。
已进行汉化处理。

功能概述

WoW 12.1 目标检测修复

在 WoW 12.1 中，某些宠物对战场景或副本内的 NPC 信息会返回受保护或秘密值，导致 Rematch 无法正确识别部分对战目标，从而出现诸如：
`Unknown (npc ID XXXXX)`
这样的显示，并阻止 Rematch 自动弹出已保存的队伍提示。

兼容性修复为宠物对战引入了一种替代的目标识别方法，使 Rematch 能够再次：
- 在战斗前识别受支持的宠物对战目标
- 显示其正确的名称
- 将目标与已保存的 Rematch 队伍匹配
- 自动显示相应的已保存队伍弹出窗口
- 在常规 NPC GUID/名称信息受限的战斗中正常工作

新增功能：敌方技能冷却监控

为 Rematch 集成了一个**敌方技能条**。
在宠物对战期间，当前敌方激活宠物的三个技能会以紧凑的图标形式显示，已添加可交互的调整项，位于 Rematch 设置项中。
<img src="images/Rematch Setting.png">

功能特性：
- 显示当前敌方宠物的全部三个技能
- 当敌方切换宠物时自动更新
- 原生暴雪宠物对战技能提示信息
- 鼠标悬停提示正确显示的伤害和命中率
- 显示强/弱宠物系别信息
- 圆角动作条风格技能图标
- 无暴雪快捷栏边框
- 可配置图标大小
- 可配置图标间距
- 可配置冷却字体大小
- 可配置冷却时间的 X/Y轴 位置
- 设置直接集成在 Rematch 选项面板中
- 配置更改即时生效，无需 `/reload`

鉴于 Akolus 的代码判断中使用了过于脆弱的文字判断
local isHeal = ...
local mentionsEnemy = ...
尤其是：
防御类技能
增益类技能
治疗
等其他非攻击类技能
这些技能的战斗日志文本并不一定符合之前代码的判断条件，所以会被错误的过滤掉。

我现在改成了更可靠的方式：
不再判断战斗记录的文字，而是直接读取战斗日志中的：
`battlePetAbil: XXXX`
然后拿这个 Ability ID 去和当前敌方宠物的：
`技能槽 1`
`技能槽 2`
`技能槽 3`
进行匹配。

也就是说，目前的判断流程是：
- 敌方释放技能
        ↓
- 获得 Ability ID
        ↓
- 当前敌方宠物技能槽
        ↓
- 找到对应 Ability ID
        ↓
- 记录冷却
        ↓
- 敌对技能冷却监控模块更新

所以现在防御、Buff、治疗等技能不会再因为技能类型而被过滤。


本项目有意不作为独立插件发布。
所有功能都直接集成到 Rematch 内部，并使用 Rematch 现有的设置系统和界面。
这样做是为了避免仅仅为了获取敌方技能和冷却信息而安装一个完整的额外宠物对战插件。

安装完成后，新选项可以直接通过以下路径使用：
`Rematch → 选项 → 敌方技能条选项`

需求
- 《魔兽世界》正式服 12.1
- Rematch
- 角色可进行宠物对战
